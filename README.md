Cara install:
- Install Arch Linux dengan memastikan untuk menambahkan package `networkmanager`. Panduan instalasi Arch Linux bisa diakses di [https://wiki.archlinux.org/title/Installation_guide](https://wiki.archlinux.org/title/Installation_guide).
- Setelah restart, jalankan:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/pikriawan/arch-linux-hyprland-setup-script/refs/heads/main/install.sh | bash
  ```
- Restart kembali.
- Login dengan memilih session `Hyprland`.
- Untuk melihat keyboard shortcuts, tekan `SUPER + /`.
